Browser distribution from live2d-widget 3.1.4 (GPL-2.0), copied without modification
from the npm package. Upstream: https://github.com/xiazeyu/live2d-widget.js

Only the browser runtime is retained. The obsolete Hexo helper, npm update checker
and OpenCollective installation dependencies are no longer installed or executed.
These legacy browser bundles are not covered by npm audit; retaining them is a
compatibility choice for the existing Cubism 2 model, not a security certification.
